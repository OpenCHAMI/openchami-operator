# Webhooks

The operator runs three webhooks: defaulting, validating, and conversion. All three live in `api/v1alpha1/openchamicontrolplane_webhook.go` (defaulting + validating) and `api/v1alpha1/openchamicontrolplane_conversion.go` (conversion). cert-manager provides the webhook TLS via the `Certificate` resource generated by `make manifests`.

## Defaulting

Runs on `CREATE` and `UPDATE` before validation.

- Sets `objectStorage.bucket = "{clusterName}-boot-images"` if empty.
- Sets `logging.logBucket = "{clusterName}-logs"` if empty.
- Sets `networking.tls.secretName = "{clusterName}-tls"` if empty.
- Sets `networking.gatewayClass = "envoy"` if empty.
- Sets `networking.tls.issuer` to a cluster-default if empty.
- Sets `database.instances = 1` if zero.
- Sets `database.storageSize = 10Gi` if zero.
- Sets `networkProbe.intervalSeconds = 30` if zero AND probes are enabled.
- Sets `services.coreDHCP.unknownLeaseDuration = "5m"` and `knownLeaseDuration = "24h"` if empty.

Defaulting is **never** a substitute for validation. It only fills gaps.

## Validation

Runs on `CREATE` and `UPDATE` after defaulting. Rejects requests that would violate any invariant.

### Invariant-driven checks

| Invariant | Check |
|---|---|
| 2 (namespace) | `clusterName` matches `^[a-z][a-z0-9-]*$` and is unique cluster-wide. |
| 3 (vault paths) | Computed prefix `openchami/{clusterName}/` is not in use by another cluster. |
| 4 (DHCP exclusivity) | When `networkProbe.enabled=false`, `services.coreDHCP.nodeSelector` does not match any node already targeted by another cluster's CoreDHCP. |
| 7 (no secrets in spec) | Spec is structurally enforced; no field accepts a credential value. |

### Field validation

| Field | Rule |
|---|---|
| `clusterName` | required, immutable, regex match. |
| `domain` | required, FQDN. |
| `platform.vault.address` | required, prefix `http://` or `https://`. |
| `platform.vault.authMethod` | enum `kubernetes` or `appRole`. |
| `platform.vault.appRoleSecretRef.name` | required if `authMethod=appRole`. |
| `platform.objectStorage.endpoint` | required. |
| `database.instances` | ≥ 1. |
| `database.storageSize` | parseable as `resource.Quantity`. |
| `networkProbe.provisionNetwork.subnet` | parseable CIDR if probes enabled. |
| `networkProbe.bmcNetwork.subnet` | parseable CIDR if probes enabled. |
| `services.coreDHCP.leaseRanges[].subnet/start/end` | parseable, in-range when probes disabled. |
| `services.coreDHCP.nodeSelector` | required when probes disabled. |
| `services.magellan.nodeSelector` | required when probes disabled. |
| `operatorChannel` | enum `stable` or `pinned`. |
| `pinnedVersion` | required when `operatorChannel=pinned`, valid semver. |

### Immutability

These fields are immutable after creation:
- `clusterName`
- `platform.vault.address` (changing it would orphan secrets at the old prefix)
- `platform.objectStorage.endpoint`

Any attempt to mutate them is rejected with a clear message pointing at [upgrade-and-versioning](upgrade-and-versioning.md).

## Conversion

The conversion webhook is a stub today — `v1alpha1` is the only served version. The hub is `v1alpha1` (`api/v1alpha1/openchamicontrolplane_conversion.go::Hub()`).

When `v1beta1` lands:
- The hub will move to `v1beta1`.
- `v1alpha1` will implement `ConvertTo` and `ConvertFrom`.
- The conversion runs server-side at every read; cached objects are stored at the **storage version**, which is bumped via `hack/migrate-storage-version.sh` (no-op patches every CR so the API server re-encodes).

See [upgrade-and-versioning](upgrade-and-versioning.md) for the full migration story.

## Where webhook config lives

| File | Purpose |
|---|---|
| `api/v1alpha1/openchamicontrolplane_webhook.go` | Defaulting + validation logic. |
| `api/v1alpha1/openchamicontrolplane_conversion.go` | Conversion (currently stub). |
| `api/v1alpha1/openchamicontrolplane_webhook_test.go` | Unit tests covering all rules above. |
| `config/webhook/` | Kustomize manifests for the webhook Service + ValidatingWebhookConfiguration + MutatingWebhookConfiguration. |
| `config/certmanager/` | The `Certificate` and `Issuer` that back the webhook TLS. |
| `config/default/` | Wires the webhook config into the controller manager Deployment. |

## Skip in dry-run mode

When `OPENCHAMI_DRY_RUN=true`, the webhooks still run — they validate, but the controller doesn't apply any resources. This is the cheapest way to lint a new fixture against the rules: `make dev-run-dry` and `kubectl apply -f` produces validation output without touching shared state.
